  title: 文化属性三层透视法
  type: framework
  source_chapter: 第十四章
  source_quote: |
    "透视社会依次有三个层面：技术、制度和文化。小到一个人，大到一个国家一个民族，任何一种命运归根到底都是那种文化属性的产物。强势文化造就强者，弱势文化造就弱者，这是规律，也可以理解为天道，不以人的意志为转移。"
  summary: |

    真正的根本原因始终在文化层面。文化属性分为强势文化(遵循客观规律)和弱势文化(期望救主/破格获取)。
    这是一条不可抗拒的规律, 不以人的意志为转移, 只能认识、遵循、利用。

- id: f02
  title: 退后一步的内耗策略
  type: framework
  source_chapter: 第三章
  source_quote: |
    "退后一步让条道儿请两个副总裁先过去,可能胜算要多一些。你办事老总裁放心,但董事局不一定放心。董事局关心的不是老总裁的遗嘱,而是利润。同时,这里还有一个资历问题,对你也是一个潜在的障碍。退一步,让两个副总裁之间的矛盾上升为主要矛盾,让他们去内耗,等他们斗得两败俱伤的时候,企业必然会蒙受损失,此消彼长,有个比较。当董事局看清楚谁是争权的、谁是干事的,自然就众望所归了,你才有可能树立真正的权威。"
  summary: |

    等他们内耗两败俱伤后, 自然产生对比效应, 最终"不争而争"。
    核心逻辑: 你的直接对手不是你的敌人, 你的真正敌人是掉进零和博弈的陷阱。

  type: framework
  source_chapter: 第十五章
  source_quote: |
    "不因上天堂与下地狱的因果关系而具有的极高人生境界,就是窄门。"
  summary: |

    1. 对市场生态的破坏性: 是否在破坏性开采市场资源, 损害长期生态?
    2. 对受益者的副作用: 让弱者短暂体验高位后跌落, 是否比从未体验过更残忍(精神绝症)?
    这是一个关于"是否要介入他人因果"的决策框架。

  type: framework

  source_quote: |
    "农户生产,农民得从吃饭睡觉的房子里挤地方,得呼吸油漆的有毒气体和立铣、打磨的有害粉尘,得听各种生产噪音。这里有劳动时间问题,有使用童工和老年工的问题,有社会保险、劳动保护和环境污染的问题……农户能拼什么?拼的就是在不是人呆的地方干不是人干的活儿,拼的就是不是人。如果纳入公司,公司在法律条款面前一天都活不下去,农民马上就会跑来跟我说这儿睡着太挤了,那儿干活不舒服,所有的矛盾都会转嫁为农户跟公司的矛盾,那时候就不是产品质量和成本问题了,是怎么伺候好爷的问题。"
  summary: |

    这是一种"让市场而非管理来解决问题"的组织设计框架。

- id: f10
  title: 当生则生决断模型
  type: framework
  source_chapter: 第四十二章
  source_quote: |
    "当生则生,当死则死,来去自如。丫头,不简单哪。"
  summary: |
    人生终极决断模型: 在每一个时刻, 判断"此情此景下应当做什么"就做什么, 不受生死、得失、情感的计算干扰。
    核心特征:
    1. 不计算后果(不因可能死而逃避, 不因可能活而苟且)
    2. 不预设剧本(不按预先设计的人生脚本生活)
    3. 活在当下(基于当下的真实判断做决定)
    这是"窄门"境界在生死抉择上的具体体现——因"应当"而非"有利"而行动。

- id: f12
  title: 悟道三段论
  type: framework
  source_chapter: 第二十章
  source_quote: |
    "悟道休言天命,修行勿取真经。一悲一喜一枯荣,哪个前生注定?袈裟本无清净,红尘不染性空。幽幽古刹千年钟,都是痴人说梦。"
  summary: |
    佛教/悟道认知的三个破除:
    1. 破命运论: "悟道休言天命,一悲一喜一枯荣哪个前生注定?" → 不要把一切归因于命运, 悲喜枯荣并非前生注定
    2. 破形式主义: "修行勿取真经,袈裟本无清净" → 穿袈裟不等于清净, 形式不等于实质
    3. 破二元对立: "红尘不染性空" → 清净不在红尘之外, 就在红尘之中; 出世与入世并非对立
    最终指向: 如果只在古刹中敲钟念经, 而不在生活中修行, 都是"痴人说梦"。
