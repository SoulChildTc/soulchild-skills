## R — 原文

> "本是后山人,偶做前堂客。醉舞经阁半卷书,坐井说天阔。大志戏功名,海斗量福祸。论到囊中羞涩时,怒指乾坤错。"
>
> — 豆豆,《遥远的救世主》第九章 (丁元英《自嘲》词)

## I — 方法论骨架

**五步自省框架** — 对抗"文人傲慢"与认知偏差的自我诊断工具：

1. **本是后山人** — 认清自己的出身、资源、起点。问自己：我今天的成就有多少来自先天禀赋或家庭背景？"后山人"不是自贬，而是对起点的诚实。

2. **偶做前堂客** — 承认机遇和运气在成功中的成分。问自己：我站在这里，多少是因为能力，多少是因为恰好遇到了风口、贵人、或时代红利？

3. **醉舞经阁半卷书,坐井说天阔** — 警惕"只读了半卷书就敢论天下"的认知陷阱。这是整个框架的核心：当你在某个领域取得一点经验就敢对全局下结论时，你很可能已经陷入了"坐井论天"的状态。解法：主动寻找反例，承认知识的边界。

4. **大志戏功名,海斗量福祸** — 检查是否在用宏大叙事掩盖真实能力。"大志"和"海斗"听起来很漂亮，但如果没有对应的积累和执行，就只是自我麻醉。问自己：我的"大志"有多少是逃避当下行动的借口？

5. **论到囊中羞涩时,怒指乾坤错** — 终极警告：当真正面对困境、失败、或"囊中羞涩"时，第一反应是归咎于外部环境，还是诚实地面对自己？这是检验前四步是否真正内化的试金石。

**使用姿势**：不需要每次走完五步，但每当感受到"愤怒"、"委屈"、"不服"时，直接跳到第五步——问自己"我是不是在怒指乾坤错？"

## A1 — 书中的应用

### 案例 1: 丁元英作《自嘲》
- 问题: 三个文人想用酒令让丁元英出丑
- 方法论使用: 丁元英"自嘲"——用一首词自贬，反而让三个文人无地自容
- 结论: 真正有实力的人不怕自嘲
- 结果: 三个文人折服，自嘲成了丁元英的"名片"

### 案例 2: 芮小丹音响事件
- 问题: 芮小丹以为4万就能配一套和丁元英一样的音响
- 方法论使用: 她后来发现音响价值40万，认识到自己"坐井说天阔"
- 结论: 她意识到自己认知的局限
- 结果: 这件事成为她深入了解丁元英的契机

## A2 — 触发场景

### 用户会在什么情境下需要这个 skill?
1. 讨论失败原因时只归咎于外部
2. 表现出过度自信(如"这个很简单")
3. 需要"泼冷水"式的自我反思
4. 分析一个项目失败时

### 语言信号
- "都怪..." / "都是因为..." / "blame"
- "这个很简单" / "this is easy"
- "我早就知道" / "I knew it"
- "他们不懂" / "they don't understand"
- "如果不是..." / "if not for..."

### 与相邻 skill 的区分
- 与 `wenhua-shuxing` 的区别: 自嘲是个人认知校准，文化属性是社会分析
- 与 `dangsheng-ze-sheng` 的区别: 自嘲是反思工具，当生则生是决断工具

## E — 可执行步骤

1. **检查"出身"**
   - 完成标准: 回答"我在这件事上有什么真正的优势? 还是只是因为运气好?"

2. **检查"书本"**
   - 完成标准: 回答"我是否真的理解这件事的全貌? 还是只读了半卷书?"

3. **检查"归因"**
   - 完成标准: 列出失败的全部原因，诚实区分"外部因素"和"自身因素"

4. **自嘲练习**
   - 完成标准: 写一句自嘲的话，诚实地承认自己的局限

## B — 边界

### 不要在以下情况使用此 skill
- 用户需要鼓励和信心时
- 情绪低落时(应先安抚，再反思)
- 纯技术问题讨论

### 作者在书中警告的失败模式
- 自嘲不是自贬——丁元英的自嘲是自信的表现
- 过度自嘲会变成自我否定

### 作者的盲点
- 自嘲需要一定的认知水平和心理安全感
- 不是所有人都能承受自我剖析
