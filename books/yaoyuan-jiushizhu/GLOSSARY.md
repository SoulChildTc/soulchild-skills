# 遥远的救世主 — 术语词典

> 本文档是 cangjie-skill 流水线的阶段 3 产出, 是全书 8 个 skill 的共享词典。

## 核心术语

### 文化属性
- **作者定义**: "透视社会依次有三个层面:技术、制度和文化。小到一个人,大到一个国家一个民族,任何一种命运归根到底都是那种文化属性的产物。"
- **与常识的差异**: ≠ 文化水平/文化传统, = 支配人的价值取舍行为的底层价值观和行为模式, 是决定个人/民族命运的根本因素
- **为什么重要**: 全书最核心概念, 所有 skill 都依赖此术语

### 强势文化
- **作者定义**: "强势文化就是遵循事物规律的文化"
- **与常识的差异**: ≠ 霸道/强势, = 认识和运用客观规律的能力
- **为什么重要**: 与"弱势文化"构成全书最核心的二元对立

### 弱势文化
- **作者定义**: "弱势文化就是依赖强者的道德期望破格获取的文化,也是期望救主的文化"
- **与常识的差异**: ≠ 弱小/弱势群体, = 等靠要的思维模式
- **为什么重要**: 书中批判的核心对象, 也是"救主文化批判"skill 的基础

### 天道
- **作者定义**: "强势文化造就强者,弱势文化造就弱者,这是规律,也可以理解为天道,不以人的意志为转移。"
- **与常识的差异**: ≠ 天意/命运, = 客观规律, 不以人的意志为转移的因果法则
- **为什么重要**: 书名核心词, 全书所有讨论的终极依据

### 救世主 / 救主
- **作者定义**: "救主的文化唯救主可说,救主不是人,是道,得救不是破了戒的狼吞虎咽,是觉悟。"
- **与常识的差异**: ≠ 宗教意义上的救世主, = 文化心理上的依赖对象
- **为什么重要**: 书名核心词, 也是"大爱不爱/救主批判"skill 的基础

### 窄门
- **作者定义**: "不因上天堂与下地狱的因果关系而具有的极高人生境界,就是窄门。"
- **与常识的差异**: ≠ 基督教原意(少数人得救), = 无条件的道德自觉
- **为什么重要**: "窄门道德决策"skill 的核心概念

### 破格获取
- **作者定义**: "强盗的本质是破格获取,破格获取与直接获取是两个不同的概念。"
- **与常识的差异**: ≠ 直接获取(公平竞争), = 不按规则、通过特殊关系或暴力获取利益
- **为什么重要**: 弱势文化的典型行为模式, 用于识别"等靠要"心态

### 杀富济贫
- **作者定义**: "神话的实质就是强力作用的杀富济贫"
- **与常识的差异**: ≠ 传统意义的劫富济贫, = 通过商业竞争和法律手段重构利益格局
- **为什么重要**: "杀富济贫竞争分析"skill 的核心概念

### 不可思议
- **作者定义**: "不可思议一词不是众生道里的对神秘事物的描述,而是如是、本来、就是如此,容不得你思议。"
- **与常识的差异**: ≠ 难以理解, = 客观规律本身的不容辩驳性
- **为什么重要**: 丁元英认知论的核心, 理解规律的前提

### 大爱不爱
- **作者定义**: 智玄大师送丁元英四个字:"大爱不爱。"
- **与常识的差异**: ≠ 不爱/冷漠, = 真正的爱是"不救"——让对象自己成长
- **为什么重要**: "大爱不爱/救主批判"skill 的核心悖论

### 精神绝症
- **作者定义**: "让井底的人扒着井沿看了一眼再掉下去是不是让他患上精神绝症?"
- **与常识的差异**: ≠ 医学上的精神疾病, = 短暂体验成功后回到原点的心理创伤
- **为什么重要**: "杀富济贫竞争分析"skill 中的关键风险指标

### 得救之道
- **作者定义**: "得救之道岂能是杀富济贫?"
- **与常识的差异**: ≠ 某一个具体方法, = 从根本上改变文化属性、摆脱弱势文化的途径
- **为什么重要**: 全书的核心问题意识
