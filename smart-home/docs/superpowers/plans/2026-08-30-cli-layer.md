# smart-home CLI 层重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 smart-home 的 CLI 抽成独立、稳定、有明确契约的底层工具层（退出码契约 + `--json` + 平台驱动抽象），支持未来接入 Home Assistant 等平台；同时把能力缓存（specs）迁到状态目录，完成全状态外置。CLI 稳定后，SKILL.md 另开计划瘦身为纯工作流。

**Architecture:** CLI 层拆为「入口 `device.mjs` + `lib/` 纯逻辑 + `platforms/<平台>/driver.mjs` 平台驱动」三层。平台差异全部封在 driver 里，上层只认**归一化能力名**（不碰 siid/piid/aiid），从而让 Home Assistant（entity_id + service）可以后接。CLI 通过「退出码 + `--json`」向上提供稳定契约，SKILL.md 不再需要让 AI 解析 JSON 猜成败。

**Tech Stack:** Node.js ≥18 内置模块（零 npm 依赖）、node:test（内置测试）、ESM

## 平台驱动接口（多平台兼容的关键）

每个平台 `cli/platforms/<name>/driver.mjs` 导出：

```js
export const id = 'xiaomi';            // 平台标识（= devices.json 的 platform）
export const displayName = '米家';

export async function login({ method })    // 'qr' | 'url'；HA 可为 token 配置
export function isLoggedIn()               // boolean
export async function discover()           // → [{ name, id, model, platform, online, capabilityStatus }]
                                           //    capabilityStatus: 'ok' | 'unsupported'
                                           //    副作用：拉取并缓存该平台能力定义到状态目录
export async function capabilities(device) // → { props, actions, keys } | null（从状态目录缓存读）
export async function act(device, kind, name, value)
                                           // kind: 'key'|'action'|'set'|'get'
                                           // → 平台原始响应对象（判定成败交给 errors.js）
```

归一化能力表形状（沿用现有 spec 格式，平台私有字段如 siid/piid/aiid 留在驱动内部）：

```js
{
  props:   [{ name, service, format, access: ['read','write'], range, values: [{value, desc}], unit, desc }],
  actions: [{ name, service, desc }],
  keys:    [{ name, desc }],
}
```

设备清单条目（`~/.grove/.data/smart-home/devices.json`）：

```js
{ name, id, model, platform }   // id = 平台原生标识（米家 did / HA entity_id）
```

**为什么这样设计**：`act(device, kind, name, value)` 让上层完全不碰 `siid/piid/aiid`——米家驱动内部把能力名映射成 siid/piid，HA 驱动映射成 entity/service 调用。这是接入 Home Assistant 的前提。

## 退出码契约

| 码 | 含义 | 典型场景 |
|---|---|---|
| 0 | 成功 | 操作被设备接受 |
| 1 | 用法/参数错误 | 缺参数、未知 flag |
| 2 | 设备未找到 | 名字匹配不到 |
| 3 | 设备不支持控制 | 无能力定义（如手环） |
| 4 | 设备拒绝 | `result.code` 非 0（如 `-704220043`） |
| 5 | 凭证缺失/失效 | 未登录 / `invalid signature` |
| 6 | 设备离线 | 云可下发但不生效 |
| 7 | 网络/超时 | 请求失败、超时 |
| 8 | 设备名歧义 | 匹配到多台 |

**关键修复**：当前设备被拒时脚本 `return` → 退出码 0，SKILL.md 只能让 AI 去解析 JSON 判断成败。新契约下设备拒绝 → 退出码 4，AI 看退出码即可。

## `--json` 输出契约

成功：
```json
{"ok":true,"op":"get","device":{"name":"小明同学","model":"fengmi.projector.025fc3","platform":"xiaomi"},"target":"volume","value":10,"data":{...}}
```
失败：
```json
{"ok":false,"op":"set","error":"device_rejected","exitCode":4,"message":"固件拒写该属性","device":{...},"data":{...}}
```

`error` 取值：`usage` | `device_not_found` | `not_supported` | `device_rejected` | `auth` | `offline` | `network` | `ambiguous`

- [ ] **Step 1: 写 `cli/lib/errors.js`**

```js
export const EXIT = {
  OK: 0,
  USAGE: 1,
  DEVICE_NOT_FOUND: 2,
  NOT_SUPPORTED: 3,
  DEVICE_REJECTED: 4,
  AUTH: 5,
  OFFLINE: 6,
  NETWORK: 7,
  AMBIGUOUS: 8,
};

export class CliError extends Error {
  constructor(code, kind, message, data = {}) {
    super(message);
    this.code = code;
    this.kind = kind;
    this.data = data;
  }
}

/** 判定平台响应是否被拒（顶层 code 非 0，或 result.code 非 0） */
export function isRejected(r) {
  if (!r || typeof r !== 'object') return false;
  if (r.code !== undefined && r.code !== 0) return true;
  const res = r.result;
  if (Array.isArray(res)) return res.some((x) => x && x.code !== undefined && x.code !== 0);
  if (res && typeof res === 'object' && res.code !== undefined) return res.code !== 0;
  return false;
}
```

```js
import fs from 'fs';
import os from 'os';
import path from 'path';
import { CliError, EXIT } from './errors.js';

export function stateDir() {
  return process.env.SMART_HOME_STATE || path.join(os.homedir(), '.grove', '.data', 'smart-home');
}

export function devicesFile() {
  return path.join(stateDir(), 'devices.json');
}

export function loadDevices() {
  if (fs.existsSync(devicesFile())) {
    try { return JSON.parse(fs.readFileSync(devicesFile(), 'utf8')).devices || []; }
    catch { return []; }
  }
  return [];
}

export function saveDevices(devices) {
  fs.writeFileSync(devicesFile(), JSON.stringify({ version: 2, updated: new Date().toISOString(), devices }, null, 2));
}

/** 返回全部候选（精确优先）；空数组 = 无匹配 */
export function findDevices(name) {
  const list = loadDevices();
  const exact = list.filter((d) => d.name === name);
  if (exact.length) return exact;
  return list.filter((d) => d.name.includes(name) || name.includes(d.name));
}

/** 解析到唯一设备；无匹配抛 DEVICE_NOT_FOUND，多候选抛 AMBIGUOUS */
export function resolveDevice(name) {
  const matches = findDevices(name);
  if (matches.length > 1) {
    throw new CliError(EXIT.AMBIGUOUS, 'ambiguous', `设备名「${name}」匹配到多台`, { candidates: matches.map((d) => d.name) });
  }
  if (!matches.length) throw new CliError(EXIT.DEVICE_NOT_FOUND, 'device_not_found', `未找到设备「${name}」`);
  return matches[0];
}
```

- [ ] **Step 2: 写 `cli/lib/capabilities.js`（归一化能力查找 + 值转换）**

```js
/** 按归一化能力名在 spec 中查找；平台私有字段（siid/piid/aiid）随对象返回，由驱动使用 */
export function findProp(spec, name) {
  return spec.props.find((p) => p.name === name || `${p.service}:${p.name}` === name);
}

export function findAction(spec, name) {
  return spec.actions.find((a) => a.name === name || `${a.service}:${a.name}` === name);
}

export function findKey(spec, name) {
  const norm = (s) => String(s).toLowerCase().replace(/_/g, '-');
  return spec.keys.find((k) => k.name === name || norm(k.name) === norm(name) || norm(k.name) === `press-${norm(name)}`);
}

/** 按 spec format 把 CLI 字符串转成目标类型 */
export function coerce(format, value) {
  const f = String(format || 'string').toLowerCase();
  if (['bool'].includes(f)) return ['true', '1', 'on', 'yes'].includes(String(value).toLowerCase());
  if (['int', 'uint8', 'uint16', 'uint32', 'int8', 'int16', 'int32', 'float'].includes(f)) return Number(value);
  return String(value);
}
```

```js
import path from 'path';
import fs from 'fs';
import os from 'os';
import { MiCloud, qrLogin } from './mi_cloud.mjs';
import { fetchAndSave } from './fetch_spec.mjs';
import { findProp, findAction, findKey, coerce } from '../../lib/capabilities.js';
import { stateDir } from '../../lib/registry.js';

export const id = 'xiaomi';
export const displayName = '米家';

function specsDir() {
  return path.join(stateDir(), 'xiaomi', 'specs');
}

function specFile(device) {
  return path.join(specsDir(), `${device.model}.json`);
}

export async function login({ method } = {}) {
  await qrLogin({ method });
}

export function isLoggedIn() {
  try { MiCloud.load(); return true; } catch { return false; }
}

export async function discover() {
  let mc;
  try { mc = MiCloud.load(); } catch { mc = await qrLogin(); }
  const list = await mc.deviceList();
  const out = [];
  for (const d of list) {
    let capabilityStatus = 'ok';
    if (d.spec_type) {
      try { await fetchAndSave(d.model, d.spec_type, { silent: true }); }
      catch { capabilityStatus = 'unsupported'; }
    } else {
      capabilityStatus = 'unsupported';
    }
    out.push({ name: d.name, id: String(d.did), model: d.model, platform: 'xiaomi', online: d.is_online, capabilityStatus });
  }
  return out;
}

export async function capabilities(device) {
  const f = specFile(device);
  if (!fs.existsSync(f)) return null;
  return JSON.parse(fs.readFileSync(f, 'utf8'));
}

/** kind: 'key'|'action'|'set'|'get'；name 为归一化能力名 */
export async function act(device, kind, name, value) {
  const mc = MiCloud.load();
  const spec = await capabilities(device);
  if (!spec) throw new Error('no-spec');
  if (kind === 'key') {
    const k = findKey(spec, name);
    if (!k) throw new Error(`unknown-key:${name}`);
    return mc.action(device.id, k.siid, k.aiid);
  }
  if (kind === 'action') {
    const a = findAction(spec, name);
    if (!a) throw new Error(`unknown-action:${name}`);
    return mc.action(device.id, a.siid, a.aiid, a.in && a.in.length ? a.in.map(() => '') : []);
  }
  if (kind === 'set') {
    const p = findProp(spec, name);
    if (!p) throw new Error(`unknown-prop:${name}`);
    return mc.setProp(device.id, p.siid, p.piid, coerce(p.format, value));
  }
  if (kind === 'get') {
    const p = findProp(spec, name);
    if (!p) throw new Error(`unknown-prop:${name}`);
    return mc.getProp(device.id, p.siid, p.piid);
  }
  throw new Error(`unknown-kind:${kind}`);
}
```

> 注意：`device.id` 来自 devices.json 的 `id` 字段（= did）。`fetchAndSave`/`capabilities` 内部已按状态目录读取（Task 2 完成后的路径）。`MiCloud.load()` 内部凭证路径不变。

const PLATFORMS_DIR = path.join(CLI_DIR, 'platforms');

/** 动态加载平台驱动；未知平台抛 NOT_SUPPORTED */
export async function loadDriver(platform) {
  const dir = path.join(PLATFORMS_DIR, platform);
  const entry = path.join(dir, 'driver.mjs');
  if (!fs.existsSync(entry)) {
    throw new CliError(EXIT.NOT_SUPPORTED, 'not_supported', `未支持的平台: ${platform}`);
  }
  return import(pathToFileURL(entry).href);
}

```js
#!/usr/bin/env node
import { loadDriver } from './lib/platforms.js';
import { loadDevices, saveDevices, resolveDevice, findDevices } from './lib/registry.js';
import { isRejected, CliError, EXIT } from './lib/errors.js';
import { formatOutput, formatHuman } from './lib/output.js';

const args = process.argv.slice(2);
const jsonMode = args.includes('--json');

async function main() {
  if (args.includes('--help') || args.includes('-h') || args.length === 0) {
    const text = await import('./help.js').then((m) => m.HELP);
    console.log(jsonMode ? JSON.stringify({ ok: true, op: 'help', help: text }) : text);
    return EXIT.OK;
  }

  if (args.includes('--login')) {
    const driver = await loadDriver('xiaomi');
    await driver.login({ method: args.includes('--url') ? 'url' : 'qr' });
    console.log(jsonMode ? JSON.stringify({ ok: true, op: 'login' }) : '✅ 登录成功');
    return EXIT.OK;
  }

  if (args.includes('--register')) {
    const driver = await loadDriver('xiaomi');
    const devices = await driver.discover();
    saveDevices(devices);
    const data = { total: devices.length, unsupported: devices.filter((d) => d.capabilityStatus === 'unsupported').map((d) => d.name) };
    if (jsonMode) console.log(JSON.stringify({ ok: true, op: 'register', data }));
    else {
      console.log(`✅ 已注册 ${devices.length} 台设备`);
      for (const d of devices) console.log(`  ${d.online ? '🟢' : '⚪'} ${d.name} (${d.model})${d.capabilityStatus === 'unsupported' ? ' ⚠️ 不支持控制' : ''}`);
    }
    return EXIT.OK;
  }

  if (args.includes('--status')) {
    const driver = await loadDriver('xiaomi');
    const hasCreds = driver.isLoggedIn();
    const devices = loadDevices();
    const data = { creds: hasCreds, total: devices.length };
    if (jsonMode) { console.log(JSON.stringify({ ok: true, op: 'status', data })); return EXIT.OK; }
    console.log(`凭证: ${hasCreds ? '✅ 已登录' : '❌ 未登录（运行 --login）'}`);
    console.log(`设备: ${devices.length ? `✅ ${devices.length} 台已注册` : '❌ 未注册（运行 --register）'}`);
    if (devices.length) {
      for (const d of devices) {
        const spec = await driver.capabilities(d);
        console.log(`  ${d.name} (${d.model}) ${spec ? '✅' : '⚠️ 设备不支持控制（无需重试）'}`);
      }
    } else {
      console.log('\n💡 初始化流程: node cli/device.mjs --login --url → node cli/device.mjs --register');
    }
    return EXIT.OK;
  }

  if (args.includes('--rename')) {
    const oldName = args[args.indexOf('--rename') + 1];
    const newName = args[args.indexOf('--rename') + 2];
    if (!oldName || !newName) throw new CliError(EXIT.USAGE, 'usage', '用法: --rename <旧名> <新名>');
    const devices = loadDevices();
    const exact = devices.filter((d) => d.name === oldName);
    const fuzzy = exact.length ? exact : devices.filter((d) => d.name.includes(oldName) || oldName.includes(d.name));
    if (fuzzy.length > 1) throw new CliError(EXIT.AMBIGUOUS, 'ambiguous', `设备名「${oldName}」匹配到多台`, { candidates: fuzzy.map((d) => d.name) });
    const dev = fuzzy[0];
    if (!dev) throw new CliError(EXIT.DEVICE_NOT_FOUND, 'device_not_found', `未找到设备「${oldName}」`);
    if (devices.some((d) => d.name === newName)) throw new CliError(EXIT.USAGE, 'usage', `已存在同名设备「${newName}」`);
    dev.name = newName;
    saveDevices(devices);
    if (jsonMode) console.log(JSON.stringify({ ok: true, op: 'rename', device: oldName, target: newName }));
    else console.log(`✅ 已改名: ${oldName} → ${newName}`);
    return EXIT.OK;
  }

  if (args[0] === 'list') {
    const devices = loadDevices();
    const data = { devices };
    if (jsonMode) { console.log(JSON.stringify({ ok: true, op: 'list', data })); return EXIT.OK; }
    if (!devices.length) { console.log('（还没有注册设备，运行 node cli/device.mjs --register）'); return EXIT.OK; }
    const driver = await loadDriver('xiaomi');
    const withSpec = [], noSpec = [];
    for (const d of devices) (await driver.capabilities(d) ? withSpec : noSpec).push(d);
    console.log(`共 ${devices.length} 台设备（可控制 ${withSpec.length} 台${noSpec.length ? `，无能力定义 ${noSpec.length} 台）` : '）'}:`);
    for (const d of withSpec) console.log(`  ${d.name}  (${d.model}, ${d.platform})`);
    if (noSpec.length) {
      console.log('不支持控制（无能力定义）:');
      for (const d of noSpec) console.log(`  ${d.name}  (${d.model}, ${d.platform})`);
    }
    return EXIT.OK;
  }

  if (args.includes('--list') || args.includes('--key') || args.includes('--action') || args.includes('--set') || args.includes('--get')) {
    const name = args.find((a) => !a.startsWith('--'));
    if (!name) throw new CliError(EXIT.USAGE, 'usage', '缺少设备名');
    const device = resolveDevice(name);
    const driver = await loadDriver(device.platform);
    const spec = await driver.capabilities(device);
    if (!spec) throw new CliError(EXIT.NOT_SUPPORTED, 'not_supported', `设备「${device.name}」不支持控制`);

    if (args.includes('--list')) {
      const data = { device, spec };
      if (jsonMode) { console.log(JSON.stringify({ ok: true, op: 'caps', device, data })); return EXIT.OK; }
      formatHuman.list(device, spec);
      return EXIT.OK;
    }

    let kind, target, value;
    if (args.includes('--key'))   { kind = 'key'; target = args[args.indexOf('--key') + 1]; }
    if (args.includes('--action')){ kind = 'action'; target = args[args.indexOf('--action') + 1]; }
    if (args.includes('--set'))   { kind = 'set'; target = args[args.indexOf('--set') + 1]; value = args[args.indexOf('--set') + 2]; if (value === undefined) throw new CliError(EXIT.USAGE, 'usage', `缺少值，如: --set ${target} 40`); }
    if (args.includes('--get'))   { kind = 'get'; target = args[args.indexOf('--get') + 1]; }

    const raw = await driver.act(device, kind, target, value);
    if (isRejected(raw)) throw new CliError(EXIT.DEVICE_REJECTED, 'device_rejected', `设备拒绝操作（result.code 非 0）`, { raw });
    if (jsonMode) console.log(JSON.stringify({ ok: true, op: kind, device, target, value, data: raw }));
    else formatHuman.result(kind, device, target, raw);
    return EXIT.OK;
  }

  throw new CliError(EXIT.USAGE, 'usage', '用法不识别');
}

try {
  process.exitCode = await main();
} catch (e) {
  if (e instanceof CliError) {
    if (jsonMode) console.log(JSON.stringify({ ok: false, op: 'error', error: e.kind, exitCode: e.code, message: e.message, ...(e.data && { data: e.data }) }));
    else { console.error('❌ ' + e.message); if (e.data && e.data.candidates) for (const c of e.data.candidates) console.error('   - ' + c); }
    process.exitCode = e.code;
  } else {
    console.error('❌ ' + (e.message || e));
    process.exitCode = EXIT.NETWORK;
  }
}
```

export const formatHuman = {
  list(device, spec) {
    console.log(`设备: ${device.name}  (${device.model}, ${device.platform} | id=${device.id})`);
    if (spec.props && spec.props.length) {
      console.log('\n属性 (--get / --set):');
      for (const p of spec.props)
        console.log(`  ${p.name}  [${p.format}${p.access && p.access.includes('write') ? '+写' : '只读'}]${p.range ? ` ${JSON.stringify(p.range)}` : ''}  ${p.desc || ''}`);
    }
    if (spec.actions && spec.actions.length) {
      console.log('\n动作 (--action):');
      for (const a of spec.actions) console.log(`  ${a.name}  ${a.desc || ''}`);
    }
    if (spec.keys && spec.keys.length) {
      console.log('\n遥控键 (--key):');
      const seen = new Set();
      for (const k of spec.keys) {
        const label = k.name.replace(/^press-/, '');
        if (seen.has(label)) continue;
        seen.add(label);
        console.log(`  ${label}  ${k.desc || ''}`);
      }
    }
  },

  result(kind, device, target, raw) {
    if (kind === 'get') {
      const val = (raw.result && raw.result[0]) || raw;
      console.log(`读取 ${target} →`, JSON.stringify(raw));
      if (val && val.value !== undefined) console.log(`  = ${val.value}`);
    } else if (kind === 'set') {
      console.log(`设置 ${target} →`, JSON.stringify(raw));
    } else {
      console.log(`操作「${target}」→`, JSON.stringify(raw));
    }
  },
};
