# 概念台账 · Docker 29.8.2

动笔前建的清单。用途：保证读者按顺序读时，每一页用到的概念都在前面讲过。

## 前置关系图

```
容器（最基础）
├── 镜像 ← 容器的来源
│   ├── tag / digest ← 镜像的标识
│   ├── 分层 ← 镜像的结构
│   └── 仓库（registry）← 镜像的存放地
├── 可写层 ← 容器独有
│   └── 数据丢失 ← 可写层的后果
│       └── 挂载 ← 数据丢失的解法
│           ├── 命名卷
│           ├── 绑定挂载
│           └── tmpfs
├── 生命周期（created → running → exited）
│   └── 退出码 ← 生命周期结束的信号
├── 网络 ← 容器之间通信
│   ├── bridge（默认）
│   ├── 自定义网络
│   └── 端口映射 ← 容器对外暴露
└── 资源限制（CPU / 内存）
    └── OOM ← 内存超限的后果
```
