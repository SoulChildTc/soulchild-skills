# 选主题

两套模板不是换配色，是两套**阅读模式**。选错要重做排版，所以先定。

---

## 一句话判断

| 用户说的话 | 选 |
|---|---|
| 「做成手册」「我要查」「方便翻」「对着做」 | **paper** |
| 「像篇文章」「我要读完」「沉浸」「通读」 | **longread** |
| 没说，或者只说「做个学习页」 | **paper**（默认） |

## 结构性差异

| | paper | longread |
|---|---|---|
| 阅读单元 | 一屏一页 | 一整本连续滚 |
| 导航 | 左栏常驻目录 | 全屏目录（`I`） |
| 依据 | 右侧常驻栏 | 节末脚注 |
| 进度 | 第几节 / 共几节 | 滚动百分比 + 右缘刻度 |
| 翻页 | `←` `→` | 无 |
| 找回位置 | 目录点章节 | 右缘刻度点格子 |

## 什么时候必须用 longread

- 单章超过 6 节，或单节超过 2 屏。分屏读会碎。
- 内容有连续论证，中途断开就接不上。
- 用户明确说要「读」，不是「查」。

## 什么时候必须用 paper

- 章节之间互相独立，跳到哪节都能读。
- 用户要一边操作一边看（跑命令时对照）。
- 参考条目多（> 100 条），需要右侧速查常驻配合。

## 两个都不合适

- 参考条目 < 8 条、内容不够撑 2 章的：**不要出读本**，出一屏速览就够。这时两套模板都能用，但 paper 的单屏形态更接近。
- 用户要的是一份可以打印的 PDF：两套都没做过打印排版，先说清楚。

## 换主题的代价

`content.json` 不用改。换主题只改一条命令：

```bash
python3 $SKILL/scripts/book.py build content.json --theme longread
```

但**写完内容再换主题要看一遍排版**：两套对正文的排法不同（paper 段间空行、longread 首行缩进），段落的视觉密度会变。如果某节在 paper 里刚好一屏，换到 longread 就不是了 —— 这通常不影响，但要知道它会发生。
