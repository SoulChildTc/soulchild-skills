# 主题 paper

一屏一页，左栏目录，`←` `→` 翻页。当手册查。

骨架：`assets/templates/paper/template.html`
引擎：`assets/templates/paper/engine.js`

**这两份都不要改。** 这份文档只在两种情况下要读：排查视觉问题，或者新增主题时对照。

---

## 阅读模式

一次显示一屏。屏幕序列是：封面 →（章首页 → 内容页 × N）× 章数。

- `←` `→` 翻页，`Esc` 关抽屉
- 左侧目录常驻（窄屏变抽屉），展开当前章的节，标已读
- 右侧「本页依据」栏常驻，窄屏落到页尾
- 底栏写上一节 / 下一节

| 块 | 呈现 |
|---|---|
| `p` | 无衬线，段间空行（1.15em） |
| `h3` | 19px 无衬线，上方 44px，下方一条细线 |
| `note` | 浅底 + 左侧 2px 墨线，标签在上方小字 |

## 章首页

- 右上角超大宋体数字水印（`rgba(28,25,23,.045)`）
- 章号 kicker + 宋体大标题 + 一句 desc
- 本章节列表，hover 左移 8px

## 窄屏

| 断点 | 变化 |
|---|---|
| ≤ 1180px | 依据栏隐藏，依据落到页尾（`.foot-src` 显示） |
| ≤ 900px | 左栏变抽屉（`translateX(-100%)`），出现 `☰` |
| ≤ 520px | 正文 16px，标题 26px，底栏的节进度条隐藏 |

## 交互约定

| 操作 | 行为 |
|---|---|
| `⌘K` / `/` | 打开参数查阅面板 |
| `←` `→` | 上一屏 / 下一屏 |
| `Esc` | 关查阅面板，或关目录抽屉 |
| 点代码块 | 复制全文，1.2s 内显示「已复制」 |

进度存 `localStorage`，key 是 `slug.seen` / `slug.pos` / `slug.font`。

## 改动时要守住

1. 入场动画**只做位移，不从 `opacity:0` 开始**。动画没跑完就不可见的页，截图和低性能设备上会整页空白。
2. 行内代码用 `overflow-wrap`，**不要 `white-space:nowrap`**。长变量名会撑破布局。
3. 行内代码样式要限定作用域（`.opt .od code` 这种层级），否则会污染 `pre code`，代码块的换行全丢。
4. 模板里不能出现任何项目名。品牌名统一走 `{{PROJECT}}` 占位符。
5. 进度 key 必须带 `slug`，否则同一台机器上两个项目会串台。

## 视觉验收

对照截图，逐项确认：

- 正文列不超过 940px，约 60 汉字一行
- 段落与段落的间距一致，没有某一段贴住下一段
- 表格首行墨线完整，最后一行有收口线
- 朱红只出现在该出现的地方（当前项、角标、行内代码、强调）
- 窄屏无横向溢出；代码块内部可横向滚动，页面本身不动
- 打印预览时分页合理（正文页内没有断在标题后）
