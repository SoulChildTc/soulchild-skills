# 主题 longread

连续长文，一次滚到底。从头读到尾。

骨架：`assets/templates/longread/template.html`
引擎：`assets/templates/longread/engine.js`

**这两份都不要改。** 这份文档只在两种情况下要读：排查视觉问题，或者新增主题时对照。

---

## 阅读模式

整本书一次铺开。**没有屏幕索引，没有翻页。** 从封面一路滚到封底。

- 顶栏只有书名、进度百分比、目录按钮、字号
- 右缘一条竖向刻度：每节一格，按章分组，鼠标悬停看标题，点击跳过去
- 左下角显示当前章名，滚过去才出现
- 目录是全屏覆盖层（`I` 或顶栏），不是侧栏
- 每节的依据是**节末脚注**，不是侧栏
- 点正文里的角标 `{{n}}`，滚到该节脚注并高亮 1.6s

## 尺寸与留白

| 项 | 值 |
|---|---|
| 正文列 | `calc(31 * var(--read))`，即 31 个汉字宽 |
| 正文 | 19px / 行高 1.95 |
| 页内边距 | `clamp(20px,5vw,56px)` |
| 顶栏 | 46px，下方一条 1px 进度线 |
| 章前留白 | `clamp(64px,11vh,128px)` |
| 节内上留白 | `clamp(52px,8vh,92px)` |

字号三档：17 / 19 / 21，存在 `slug.zoom`。列宽跟着字号变，一行字数不变。

| 变量 | 值 | 用途 |
|---|---|---|
| `--white` | `#FBFAF7` | 底色，冷白纸 |
| `--cream` | `#F3F0E8` | 代码块底 |
| `--cream-2` | `#E8E4D8` | 代码块 hover |
| `--black` | `#141513` | 正文黑、章横带底 |

| `--gray-2` | `#6A6C62` | 次级文字 |
| `--gray-3` | `#6F7164` | 小字标签（白底 4.77:1） |
| `--gray-4` | `#A8AA9E` | **只用于线条和装饰，不承载文字** |
| `--green` | `#14624A` | 墨绿，唯一强调色 |

设计约束：**正文用宋体，标题用黑体。** 这个组合是这套模板的核心区分点。

## 文字排布

中文按书排，不按网页排：

- 段首**首行缩进两字**（`text-indent:2em`）
- 段间**不留空行**（`margin-bottom:.42em`）
- 节标题下第一段**不缩进**，让文字顶格起排
- 行高 1.95，`line-break:strict`

**不要用首字下沉。** 中文会被拆成「虚 / 拟机」，读起来是断的。

## 各块的样子

| 块 | 呈现 |
|---|---|
| `p` | 宋体，首行缩进，段间紧排 |
| `h3` | 黑体 25–36px，编号在左上方偏移对齐 |
| `note` | 墨绿浅底，标签**竖排**在左 |
| `warn` | 琥珀浅底，标签竖排 |
| `code` | 米色块 + 顶部 `figcaption` 语言标签 + 顶边细线 |
| `table` | 首列加粗，表头全大写等宽，行线极细 |
| `kv` | 键在上、值在下，逐行分隔 |
| `split` | 两栏，只有一条上边线 |
| `opts` | 大号宋体数字挂左侧，推荐项数字转墨绿 |

## 章横带

整幅反白：

- 底色 `--black`，通栏（破出正文列宽）
- 右上角超大描边数字（`-webkit-text-stroke`），空心
- 章号 kicker + 黑体大标题 + 一句 desc
- 读完该章后底部出现一个绿点 + 「本章已读完」

## 窄屏

| 断点 | 变化 |
|---|---|
| ≤ 1180px | 右缘刻度贴边 |
| ≤ 860px | 刻度隐藏，左下角章名隐藏；方案编号改为左浮动；旁注标签转横排 |
| ≤ 520px | 内边距 18px，章横带的数字缩到 88px，页脚信息换行 |

## 交互约定

| 操作 | 行为 |
|---|---|
| `⌘K` / `/` | 打开参数查阅面板 |
| `I` | 开 / 关全屏目录 |
| `Esc` | 关查阅面板，或关目录 |
| 点右缘刻度 | 跳到该节 |
| 点角标 | 滚到本节脚注并高亮 |
| 点代码块 | 复制全文，1.3s 内显示「已复制」 |

进度存 `localStorage`，key 是 `slug.seen` / `slug.pos` / `slug.zoom`。
`slug.pos` 存的是滚动位置。

## 改动时要守住

1. **不要给 `p` 加首字下沉。** 中文单字被放大后与后文脱节。
2. 正文列的宽度用 `calc(N * var(--read))` 算，不要写死 px。字号变大时列要跟着变宽，否则一行字数会从 31 掉到 26。
3. `--gray-4` 只给线条用。任何文字用它会低于 3:1，读不清。
4. 滚动入场的 `.rise` 只做位移，**不改透明度**。
5. 进度靠节在视口里的位置算，不靠 CSS `scroll-snap`。用户可能一次跳很远。

## 视觉验收

对照截图，逐项确认：

- 一行 31 个汉字左右，不会宽到要回扫
- 段首缩进两字，段间没有多余空行，读起来像书不像网页
- 正文是宋体，标题是黑体，两者对比明显
- 章横带通栏，两侧没有留白边界
- 右缘刻度：当前节粗且绿，已读节灰，未读节更浅
- 顶栏进度百分比与滚动位置一致
- 角标点击后确实滚到了对应脚注，且高亮可见
- 窄屏无横向溢出，表格内部可横向滚动
